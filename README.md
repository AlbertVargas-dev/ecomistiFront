# Ecomisti Front 

Frontend de una plataforma social universitaria desarrollada con **React**, orientada a facilitar la interacción de los usuarios con el sistema de puntos y el canje de recompensas.

## Tecnologías

- **React** — Biblioteca para construir interfaces de usuario.
- **TypeScript** — Lenguaje de programación tipado.
- **pnpm** — Gestor de paquetes.

## Funcionalidades

- Interfaz de usuario para la plataforma social universitaria.
- Visualización y gestión de puntos.
- Consulta de recompensas disponibles.
- Interfaz para el canje de puntos.
- Integración con el backend mediante una API REST.
